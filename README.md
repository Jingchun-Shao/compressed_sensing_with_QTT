# Compressed sensing with quantized tensor trains

MATLAB code and numerical results for compressed sensing of tensorized
signals that combine low tensor-train rank with sparse, low-order interaction
structure. The experiments use subsampled Walsh--Hadamard measurements and
compare structure-aware, spectral, random, and near-zero initializations for
alternating linear scheme recovery.

## Repository structure

- `code/src`: tensor utilities and TT recovery routines.
- `code/experiments/rip`: empirical restricted-isometry experiments.
- `code/experiments/initialization`: initialization-error experiments.
- `code/experiments/recovery`: recovery experiments.
- `code/results/data`: final synthetic data generated by the experiments.
- `code/results/figures`: final figures in portable PDF or PNG form.
- `code/sanity checks`: small numerical and visualization checks.

Historical experiments, raw logs, and generated MATLAB figure files are excluded from this release.

## Requirements

- MATLAB with `fwht` and `ifwht` (Signal Processing Toolbox).
- [TT-Toolbox](https://github.com/oseledets/TT-Toolbox), providing
  `tt_tensor`, `tt_random`, and `my_chop2`.

The experiments were written for binary tensorization, so an ambient vector
of length `2^d` is represented as a `d`-way tensor with mode size two.

## Setup

From the repository root, start MATLAB and run:

```matlab
addpath('code');
setup_qtt_paths('path/to/TT-Toolbox');
```

If TT-Toolbox is already on the MATLAB path, omit the argument:

```matlab
setup_qtt_paths;
```

Run the lightweight verification before launching the full experiments:

```matlab
run(fullfile('code', 'sanity checks', 'smoke_test.m'));
```

## Reproducing the reported experiments

The experiments are grouped by purpose:

| Result | Scripts |
| --- | --- |
| Starting Fourier/random-TT baseline | `code/experiments/rip/baselines` |
| Empirical RIP scaling | `code/experiments/rip/paper_sliding_window` |
| Initialization scaling | `code/experiments/initialization/paper_initialization_error` |
| ALS recovery scaling | `code/experiments/recovery/paper_recovery` |

For example, the measurement-scaling RIP experiment can be run from the
repository root with:

```matlab
run(fullfile('code', 'experiments', 'rip', 'paper_sliding_window', ...
    'rip_measurement_scaling.m'));
```

The experiment scripts define their parameters at the top, use
`rng default` for reproducibility, and save results beneath `code/results`.
The full settings use many independent trials and can take substantially
longer than the smoke test.
